# 定价优化 & 促销机制深度指南

## 节令氛围菜：定价逻辑完全不同

**在判断是否涨价之前，先判断这道菜的用户心理属性。**

节令属性强的菜（粽叶蒸排骨/蟹黄豆腐/年夜饭套餐/情人节拼盘），用户**不是在买食物，而是在买仪式感和氛围**，因此价格弹性天然低于普通菜品。

| 菜品属性 | 用户购买动机 | 价格弹性 | 定价策略 |
|---------|------------|---------|---------|
| 普通家常菜 | 吃饱/解馋 | 高（容易比价） | 竞品锚点定价 |
| 特色招牌菜 | 吃不到的味道 | 中 | 成本+溢价 |
| **节令氛围菜** | **仪式感/时令感/应景** | **低（用户不敏感）** | **身份升级定价** |

### 高手节日策略：不涨价，提身份感

**反直觉建议：节日期间，不要直接涨价。**

直接涨价（68→78元）的问题：
- 老客看到原价记忆，产生"节日涨价感"，体验负分
- 容易被负面评价

**更高效的做法：保持原价 + 节日限定包装**

```
普通版：粽叶蒸排骨  58元
→ 节日版：端午粽香蒸排骨·限定款  58元（同价，但有：节日命名+限量标签+专属摆盘）
```

这个做法的本质是：**用"稀缺性"替代"价格优惠"**——用户感知更好，且不损失毛利。

### 节日限定命名策略

普通菜名 → 节日限定名的三个改造维度：

| 维度 | 改造方法 | 示例 |
|-----|---------|------|
| 节日符号化 | 加入节日关键词 | 粽叶蒸排骨 → 端午粽香排骨 |
| 地域/食材溯源 | 强调原料特别性 | 蒸排骨 → 岭南手工粽叶排骨 |
| 限量感 | 强调稀缺/时令 | （任何菜）→ 加"限时季节款""每日限量"角标 |

**节日期间真正该做的事**：

1. 改节日名称（必做，5分钟改菜单）
2. 做节日主推套餐（让这道菜成为套餐核心）
3. 强化限量感（"每日限量X份""节日限定"）
4. 用节日套餐激活这道菜的场景感，而不是让它单独硬卖

## 第一部分：定价优化

### 定价三角模型

任何菜品的最优定价都在三个约束的交集里：

```
成本底线（不能亏）
    ↓
竞品锚点（顾客有参照系）
    ↓
价格心理（顾客感知值）
```

**成本底线计算**：
```
定价下限 = 食材成本 ÷ (1 - 目标毛利率)
示例：食材成本22元，目标毛利率60% → 定价下限 = 22 ÷ 0.4 = 55元
```

### 联网搜索竞品定价（必须主动执行）

当用户问"这道菜定多少钱合适"时，**直接搜索**，不要说"建议您自己去看看"：

**搜索词模板**：
- `[城市] [菜品名] 餐厅 价格 2025`
- `美团 [菜品名] [城市] 价格区间`
- `大众点评 [品类] [城市] 人均消费`
- `[品类] 餐饮 平均毛利率 行业数据 2024`

**搜索结果处理**：
1. 提炼价格分布区间（低/中/高端各什么价位）
2. 找出竞争最集中的"主流价格带"（最多竞品集中的区间）
3. 判断用户当前定价在市场中的位置
4. 给出调整建议

如果用户提供了竞品的大众点评/美团链接，用 agent-browser 直接抓取菜单页面，提炼价格分布和爆款分布。

### 定价建议输出格式

```
【[菜品名] 定价优化分析】

成本基础：
  食材成本：22元/份
  在目标毛利率60%下，定价下限 = 55元

市场参考（基于实时搜索数据）：
  同城同类菜品价格区间：48-128元
  主流竞争价格带：62-78元（竞争最激烈）
  溢价产品价格带：95元+（品质/装修更好的）

您当前定价：68元（位于主流价格带中段）

分析结论：
  → 您的成本控制较好（成本22元，竞品普遍25-35元）
  → 当前定价尚有空间，可以考虑涨至75-78元

建议定价：75元（毛利率70.7%，心理上比68元多7元但仍低于80元整数门槛）

测试方案：
  先涨5元（68→73元），观察30天销量变化
  若销量下降<10%，继续涨至目标价
  若销量下降>20%，回到68元并检查其他原因（摆位/推荐不足）
```

### 价格心理学速查表

| 技巧 | 说明 | 适用场景 |
|------|------|---------|
| **尾数定价** | 以 8/9 结尾（68/79/98） | 大众消费菜品，增加亲和感 |
| **整数定价** | 整数（80/120/300） | 高端菜品/招牌菜，体现品质感 |
| **锚定效应** | 菜单里放1-2道高价菜 | 让其他菜"显得划算"，例：288元的招牌套餐让168元显合理 |
| **价格区间集中** | 主力菜品价格带控制在±20%内 | 避免顾客选择困难，主力带58-88元最理想 |
| **心理门槛** | 避免跨越整数门槛（98元→100元感知差大） | 定价时主动规避 |

## 第二部分：促销机制设计

### 促销目标匹配表

先明确促销目标，再选机制——不同目标适合不同工具：

| 促销目标 | 适合机制 | 关键注意点 |
|---------|---------|----------|
| 提升客单价 | 满减（门槛设客单价×1.3-1.5）、套餐升级 | 门槛不能太高，否则顾客放弃追单 |
| 提升到店频次 | 打卡积分、储值充值、会员日 | 需要会员系统支持，可协同 `member-repurchase-campaign` |
| 消化特定库存 | 定向折扣（限特定菜品）、该菜品做赠品 | 只针对问题菜，不要全场打折 |
| 引流新客 | 新人首单特惠、平台团购低价引流品 | 引流品毛利可低，但不能亏本 |
| 节假日冲量 | 节日专属套餐、限时特价、平台大促 | 提前21天规划，提前7天平台报名 |

### 节假日节点判断（结合 currentDate）

每次讨论促销时，先判断当前时间节点，给出具体建议：

```
判断逻辑：
距节假日 > 21天 → 现在规划菜单/套餐设计，还来得及
距节假日 7-21天 → 进入筹备期：锁定菜单、备食材、做预热内容
距节假日 < 7天  → 短期冲量：限时特价、平台活动报名（已是最后机会）
节后 1-2周      → 清尾货策略，为下个节点开始规划
```

**中国餐饮关键节点（按月）**：

| 时间 | 节点 | 餐饮核心机会 |
|------|------|------------|
| 1-2月 | 元旦、春节 | 年夜饭套餐（提前45天规划）、春节礼盒/伴手礼 |
| 2月 | 情人节（14日） | 双人套餐、玫瑰甜品、浪漫氛围加价 |
| 3月 | 妇女节（8日） | 女性顾客专属优惠、精致下午茶 |
| 4-5月 | 清明、五一 | 户外踏青便当、家庭聚餐套餐 |
| 6月 | 端午、父亲节 | 粽子关联菜品、父亲节豪华套餐 |
| 7-8月 | 暑假 | 学生套餐/家庭欢聚套餐、冰品/夏日特饮 |
| 8-9月 | 七夕、中秋 | 情侣套餐、月饼关联、家宴套餐 |
| 10月 | 国庆 | 节日大餐套餐（提前30天规划） |
| 11月 | 双十一 | 预售券、储值活动、平台大促 |
| 12月 | 圣诞、元旦前 | 西式融合菜、跨年套餐 |

### 满减档位设计公式

```
满X减Y 设计原则：
  X（门槛）= 客单价 × 1.3-1.5
  Y（优惠）= X × 10-15%（让顾客有感知，但不超过毛利空间）

示例（客单价80元）：
  满100减10（轻度促进加单：再点一份小菜即可到达）
  满150减20（适合聚餐：3人桌自然消费能到达）
  满200减35（适合大桌/包厢）
```

**常见错误**：
- 门槛设太高（如客单80元，满300减20）→ 顾客根本不在乎，没有追单动力
- 优惠给太少（满100减3）→ 顾客看不上，还占菜单版面
- 全场所有菜都参与满减 → 高毛利菜和低毛利菜一视同仁，亏本促销

### 赠品策略

**赠品的黄金法则：高感知价值、低实际成本**

| 赠品类型 | 毛利率参考 | 适用场景 | 备注 |
|---------|---------|---------|------|
| 特色小菜/凉菜 | 70-80% | 日常满减赠品 | 顾客感知价值高，成本低 |
| 特调饮品 | 75-85% | 套餐配送、节日专属 | 边际成本极低，印象深 |
| 季节甜品/小食 | 65-75% | 节假日礼遇 | 增加仪式感和品牌记忆 |
| 食材特产/伴手礼 | 50-65% | 高价值顾客回馈 | 非日常使用，节假日节点 |

**绝对禁忌**：不要用主力明星菜做赠品，会破坏顾客对该菜品的价值感知。

### 促销方案输出格式

```
【[节点/目标] 促销机制设计方案】

背景分析：
  当前日期：[日期]，距[节假日]还有X天，处于[规划/筹备/冲量]阶段
  当前客单价：约XX元，目标提升至XX元

推荐机制：[满减/套餐/赠品/组合]

具体设计：
  档位一：满XX减XX（面向[场景]）
    → 触发条件：顾客点餐达到门槛
    → 推荐追单菜品：[高毛利、低决策难度的菜品]

  档位二：满XX减XX（面向[场景]）
    → ...

赠品建议：
  满XX元赠：[菜品名]（成本约X元，顾客感知价值XX元）
  为什么选这道：[毛利高/顾客常说好吃/差异化]

配套动作：
  → 服务员话术：当顾客快到门槛时，主动说"您再加一个[推荐菜]就能减XX元"
  → 菜单标注：在赠品旁加"凑单必选"角标
  → 平台设置：[美团/饿了么/堂食POS]的配置方式

预期效果：
  客单价提升预估：+XX元/桌（即 +X%）
  整体毛利率影响：[毛利率预计从XX%变为XX%]
```
