# LingNeng Migration Docs

This directory stores durable specs and implementation plans for the LingNeng
runtime migration on top of this Hermes fork.

Use these paths for new migration documents:

- Specs and design docs: `docs/lingneng-migration/specs/`
- Implementation plans: `docs/lingneng-migration/plans/`

The old LingNengAI service and docs repository remain reference material only.
New migration decisions should be committed with this Hermes repository so a
fresh Codex session in this checkout has the complete context.
